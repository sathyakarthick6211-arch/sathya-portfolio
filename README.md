# Sathya — Portfolio

Personal portfolio site for Sathya, a full-stack web developer. Static HTML, CSS and vanilla JavaScript with no build step.

## Structure
- `index.html` — the single-page site
- `styles.css` + `tokens/` — design tokens (colors, type, spacing, effects)
- `site/` — page styles, content (`data.js`), animations (`scenes.js`), behaviour (`app.js`), résumé PDF

## Run locally
Open `index.html` in a browser, or serve the folder:

```
npx serve .
```

## Deploy
Deployed on Vercel as a static site (no build command, output directory = root).
